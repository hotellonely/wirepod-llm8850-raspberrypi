# wirepod-llm8850-raspberrypi

Documenting how to utilize the LLM8850 AI module for your Anki Vector robot using a localized (on-device) large language model, powered by a Raspberry Pi running WirePod.

## 📖 Documentation

Full setup guides, configuration details, and troubleshooting tips are available in the **[GitHub Wiki](https://github.com/hotellonely/wirepod-llm8850-raspberrypi/wiki)**.

Start with the **[Home page](https://github.com/hotellonely/wirepod-llm8850-raspberrypi/wiki/Home)** for an overview and links to all guides.

## Quick Overview

| Component | Description |
|-----------|-------------|
| **Anki Vector** | The robot that runs the local LLM responses |
| **WirePod** | Open-source server replacement for Anki/DDL cloud services |
| **LLM8850** | AI accelerator module providing on-device LLM inference |
| **Raspberry Pi** | Host hardware running WirePod and the LLM8850 |
